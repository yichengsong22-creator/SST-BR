# Binder guide

The Binder badge opens `notebooks/00_quick_start.ipynb` directly. Choose
**Run > Run All Cells**. The notebook uses `DemoCore`, deterministic synthetic
signals, complete public evaluation, and the published method diagram.

The exact-core safety interface is not called, so Run All produces no expected
error or red traceback. No private package, network download, local path, or
manual input is required.

Update the badge's GitHub owner/repository placeholder before public upload.
