# Environment

The pinned scientific stack matches the successful reproduction environment:

- Python 3.11 in Binder
- NumPy 2.4.3
- SciPy 1.17.1
- pandas 2.3.3
- scikit-learn 1.8.0
- joblib 1.5.3
- PyYAML 6.0.3
- Matplotlib 3.10.7

Notebook tooling is pinned in `requirements.txt` and `binder/environment.yml`.
The full RHB run should use these scientific-library versions.
